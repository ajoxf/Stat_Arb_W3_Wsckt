Self-Learning (AI Auto-Tune)
After every closed trade, Claude analyses the outcome and stores a structured learning. When Auto-Tune is on, it will automatically adjust parameters if 3 or more consecutive analyses agree on the same change with ≥70% confidence. Changes are clamped to safe corridors (max ±0.2 per adjustment).

Live Trading Pre-Flight Checklist
  • Use the OKX Server Mode toggle above to switch from Demo → Live
  • Verify your OKX API key has Trade permissions (not read-only)
  • Confirm position size and max position size below match your risk budget
  • Confirm futures leverage is ≤ 5x for a new live account
  • Set a stop-loss threshold (e.g. 3.5–4.0σ) — never disable it in live mode
  • Hurst filter should remain enabled to avoid trending markets
  • Monitor closely for the first 24 hours after going live

OKX API Keys
Required API Permissions

When creating your OKX API key, select only these permissions:

Read - View account balances and positions
Trade - Place and cancel orders
Withdraw - DO NOT enable this!
Transfer - Not needed
Security: With only Read + Trade permissions, your funds can never be withdrawn. The bot can only trade within your account.

The passphrase you set when creating the API key on OKX

  1. Log in to your OKX account
  2. Go to Profile → API (or navigate to API management)
  3. Click "Create API Key"
  4. Set a name (e.g., "Trading Bot")
  5. Create a passphrase (you'll need this)
  6. Select permissions:
    • ✓ Read
    • ✓ Trade
    • ✗ Withdraw (leave unchecked!)
  7. Complete verification (2FA, email, etc.)
  8. Copy your API Key, Secret Key, and remember your Passphrase
